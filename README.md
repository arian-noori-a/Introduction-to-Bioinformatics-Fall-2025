# Introduction to Bioinformatics

Practical assignments for **Introduction to Bioinformatics**, implemented in R.

## Contents

| Homework | Topics |
|---|---|
| **HW1** | R fundamentals for bioinformatics, sequence utilities, basic statistics, multiple testing, clustering, UMAP/DBSCAN, and PCA |
| **HW3** | Gene-expression analysis using GEO data: QC, metadata alignment, PCA, normalization, differential-expression analysis with edgeR/limma-voom, volcano plots, and heatmaps |

## Repository Structure

```text
HW1/
  intro_to_r_bioinformatics.ipynb
HW3/
  gene_expression_analysis.ipynb
```

## Main Tools

- R
- GEOquery
- edgeR
- limma
- pheatmap
- ggplot2
- dplyr
- dbscan
- umap

Only the practical notebooks are included; assignment reports and documents are excluded.
